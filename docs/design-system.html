Workboard

רשימות מקובצות שקטות בסגנון iOS, צבע אחד שמשמעותו "כאן ועכשיו", ואלמנט נועז אחד לכל מסך. הקובץ כתוב כך שגם מודל יוכל לקרוא אותו: הטוקנים כ־JSON בראש העמוד, ה־CSS המקורי בתגית אחת, וכל דוגמה כאן היא markup אמיתי עם שמות המחלקות של המערכת.

עקרונות (חשוב יותר מכל ערך בודד)

אם משכפלים לאתר אחר, אלה הכללים שיוצרים את התחושה.

  1. RTL קודם: רק מאפיינים לוגיים (margin-inline-start, inset-inline-end, border-block-start). אף פעם left/right.
  2. שקט כברירת מחדל: רקע אפור, קבוצות לבנות מעוגלות (14px) עם קווים דקים. הנועזות מרוכזת במקום אחד — כרטיס הגרדיאנט.
  3. צבע אחד = משמעות אחת: accent = אינטראקטיבי / ההקשר הנוכחי · ירוק = בוצע · אדום = באיחור או מחיקה · ענבר = ממתין. צבעי ההקשר לא מסמנים סטטוס.
  4. סטטוס כנקודה או pill בגוון, לא כגוש צבע מלא. טקסט על גוון ≥ 4.5:1.
  5. בהיר וכהה תוכננו יחד (כהה: רקע שחור אמיתי, משטחים ‎#1C1C1E, accent בהיר יותר).
  6. גדלים ב־rem כך שגודל הטקסט של המערכת מגדיל הכל. מטרות מגע ≥ 44px. שדות בטלפון ≥ 16px (אחרת iOS עושה זום).
  7. ניווט: 4 לשוניות לכל היותר במעגן זכוכית צף, וכפתור פעולה עגול לידו. לשונית מנווטת — לא מבצעת.
  8. גיליונות למשימה ממוקדת: אחד בכל פעם, ידית גרירה, החלקה למטה לסגירה, וכפתור סגירה גלוי.
  9. מחיקה = ביטול ב־toast, לא חלון אישור (אלא אם בלתי הפיך).
  10. כתיבה: קצר וישיר; הכפתור אומר מה יקרה ("הסר מהרשימה" ולא "אישור"); פונים לאדם במגדר שלו; מצב ריק מזמין לפעולה הבאה.
  11. מספרים, שעות ומזהים: ספרות טבלאיות (tabular-nums) ובידוד עם <bdi> בתוך טקסט עברי.
  12. אייקונים: קו על רשת 24, עובי 1.8, קצוות מעוגלים, currentColor. דקורטיבי ← aria-hidden; כפתור אייקון ← aria-label.

צבע

צבעים סמנטיים בלבד (כמו ב־iOS). אין צבע קשיח בתוך רכיב — הכל דרך משתנים. ההחלפה בין בהיר לכהה בראש העמוד מראה את שני הסטים.

תנועה

קצרה, תכליתית, ניתנת לעצירה. Spring שיורש את מהירות האצבע. Reduce Motion ← רק שקיפות.

press         transform: scale(.96)  80ms ease-out        (check circle: scale(.88))
popover       rise 180ms cubic-bezier(.2,.8,.2,1): translateY(8px) scale(.98) → none
phone sheet   slide up 280ms cubic-bezier(.2,.8,.2,1); drag 1:1, rubber-band up,
              dismiss if velocity > 600px/s or projected landing > 40% of height
swipe rows    1:1 tracking, ~10px hysteresis, flick ≥ 450px/s decides,
              long swipe > 55% width arms the primary action (+10ms haptic)
reduced       @media (prefers-reduced-motion: reduce) { no animation; opacity/colour only }
